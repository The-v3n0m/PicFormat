# JarFormat

Welcome to the Jar Format Tool! This tool formats your JAR files, and makes them readable to you!

To use:

1. Clone the repository

```bash
git clone https://github.com/The-v3n0m/PicFormat.git
```
2. Create a Virtual Environment

```bash
python3 -m venv venv
```

3. Enter that virtual environmnet 

```bash
.\venv\Scripts\activate
```

4. Install Pillow

```bash
pip install pillow
```

5. Run the tool

```bash
./PicFormat.py infile outfile
```
